# 真人对战接入准备

当前只开放本地机器人练习。大厅不展示虚构在线房间；真人模式不创建房间、不扣费。历史保留已有本地记录。

`app/battle/multiplayer-contract.ts` 定义下一步传输接口，尚未连接服务端。

下一步实现顺序：
1. 服务端认证，数据库 rooms、participants、rounds、drops 与账本；余额不再信任 localStorage。
2. 创建/加入采用事务与 requestId 幂等键；加入校验容量、状态、余额，避免双重扣款；取消等待房退款。
3. 服务端生成随机结果及价格快照、决定胜负，唯一结算记录发放背包。前端动画完成不触发经济结算。
4. 大厅每 3 秒、房间每 1 秒读取带 revision 的快照，支持取消请求；随后可替换 SSE/WebSocket。用 roundStartedAt 同步动画，重连不重抽。
5. 两个不同登录客户端验证同时加入、断线重连、取消退款、重复请求、平局、结算仅一次。

本地练习记录与未来真人记录必须区分来源；不能把旧本地模拟结果当作服务器认证的对战。
